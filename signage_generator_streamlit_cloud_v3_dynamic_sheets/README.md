# HMG 사이니지 스케줄 생성기 - Streamlit Cloud v3

## 변경 내용

- 업로드한 엑셀에서 `스케줄` 시트를 제외한 모든 시트를 자동 감지합니다.
- 감지된 시트명이 UI 드롭다운에 자동 표시됩니다.
- 원본 엑셀에 시트를 추가하거나 시트명을 수정해도 앱 코드를 수정할 필요가 없습니다.
- 날짜 행 추가, 개별 삭제, 전체 초기화를 지원합니다.
- 선택한 날짜와 시트 순서대로 출력 시트에 타임테이블을 누적 입력합니다.

## 사용 방법

1. Streamlit Cloud에 이 폴더를 GitHub 저장소로 배포합니다.
2. 앱에서 기준 엑셀 파일을 업로드합니다.
3. 출력 시트명은 기본값 `스케줄`을 사용합니다.
4. 날짜별로 원하는 타임테이블 시트를 선택합니다.
5. `엑셀 생성` 버튼을 누른 뒤 완성 파일을 다운로드합니다.

## 원본 엑셀 구조

- 출력 시트: `스케줄`
- 타임테이블 원본 시트: 출력 시트를 제외한 모든 시트
- 필수 헤더: 날짜, 알람시간, 시작예정시각, 프로그램명, 렉처룸

## 배포 파일

- `app.py`
- `requirements.txt`
- `.streamlit/config.toml`
